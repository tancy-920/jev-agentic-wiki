# Publication Scope

The upload-ready repository is generated by `python scripts/prepare_github_release.py`
under `release/github-ready/`. Upload that directory's **contents**, including hidden
files, or extract `release/jev-agentic-wiki-github-ready.zip`. Do not upload the entire
development workspace. No repository or remote publication is created by this script.

## Included

| Material | Why it is needed |
|---|---|
| English root and experiment READMEs | Results, comparison design, interpretation and reproduction commands |
| `experiments/wiki_graph_value/results/` | Machine-readable headline results, with per-case rows |
| Frozen experiment inputs, original responses/usage and item-level AI reviews | Inspect and recompute the claims, including unsupported answers |
| `data/history/` inside the experiment artifact | Preserve relevant graph-QA zero/negative evidence and sensitivity controls |
| Normalized corpus, source catalog, exact chunk spans, complete articles and graph | Portable offline reproduction; no dependence on ignored local indexes |
| Frozen provider/retrieval code and standalone reproduction tests | Recompute results and optionally rerun retrieval or capped generation |
| Current `src/`, `frontend/`, article files and two configs | Current local application, including optional JEV depth selection |
| Curated scripts, UI tests, assets, package lock and dependency notices | Restore local inputs, build the synchronized demo and test presentation |
| `.env.example`, `.gitattributes`, ignore rules and CI | Credential template without keys; exact-byte artifact integrity; offline checks |

`data/source_index_metadata.json` in the experiment artifact is a small historical
descriptor required by the article provenance hash. It contains no vectors or
Qdrant storage and is not a usable prebuilt index.

## Excluded

Development handoffs/status histories, intermediate narrative reports, one-off repair
and accounting runners, unrelated early experiments, private request grants, logs,
crash/temp files, local output folders, Git history, environments, dependency caches,
downloaded PDFs, weights and generated vector stores are excluded. Static build
output is regenerated from committed assets; the existing public demo remains linked.

Duplicate narrative reports and historical runner copies were removed from the public
experiment artifact. Their original development records remain locally archived.
Relevant failures and adverse judgments remain in the published JSON; cleanup does
not remove contradictory evidence or turn AI labels into human approval.

## Before pushing

Run the README's offline reproduction and tests, and regenerate the static build when
needed. `PUBLICATION_MANIFEST.json` lists exact release files and SHA256 values.
The release builder rejects private/heavy file types and credential-shaped strings;
this is a bounded export check, not a promise about an arbitrary existing Git history.

Publish from a fresh repository rooted at the prepared directory. Avoid importing the
development workspace's `.git` directory. No license for third-party sources is
overridden; their provenance remains in the source catalog. This preparation does not
choose a new legal license on the owner's behalf.
